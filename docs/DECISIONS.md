## 2026-08-11 — Initial Project Tracking Setup
**Decision:** Adopt Master Prompt rules for tracking decisions, logs, and execution traces.
**Alternatives considered:** Manual unstructured tracking or no tracking.

## 2026-08-11 — Tracking Files Folder Location
**Decision:** Store tracking files (`DECISIONS.md`, `PROJECT_LOG.md`, `EXECUTION.md`) inside a dedicated `docs/` directory.
**Alternatives considered:** Keeping tracking files in the project root directory.
**Reasoning:** Keeps the root workspace clean and consolidates project documentation in one folder.
